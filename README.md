# 부산 보물 탐험대

부산의 대표 문화유산을 카드로 만나며 배우는 초등 사회과 보드게임입니다. 
학생들이 직접 조사한 문화유산의 내용을 바탕으로 클로드 바이브코딩으로 제작했습니다.

## 소개

**부산 보물 탐험대**는 부산의 문화유산 22가지를 카드로 익히는 짝 맞추기형 메모리 보드게임입니다.
카드를 뒤집어 같은 유산의 짝을 찾고, 시대별로 모아 점수를 얻으며 부산의 역사와 오늘날 모습을 자연스럽게 배울 수 있습니다.

## 게임 정보

* 대상: 초등학교 4학년
* 인원: 2~4명
* 시간: 20~30분
* 구성: 카드 48장

  * 유산 카드 44장
  * 특수 카드 4장

## 주요 특징

* 부산 문화유산 22종 수록
* 선사·가야, 통일신라·고려, 조선, 근대·전쟁, 생활·시장 등 5개 시대 구분
* 짝 맞추기와 점수 계산을 결합한 간단한 규칙
* 특수 카드로 전략적 재미 추가
* 사회과 수업, 지역화 학습, 문화유산 교육에 활용 가능

## 기본 규칙

1. 카드를 모두 섞어 뒷면이 보이게 펼칩니다.
2. 차례가 되면 카드 2장을 뒤집습니다.
3. 같은 유산 카드가 나오면 짝을 가져가고 설명을 읽습니다.
4. 짝을 맞추면 한 번 더 진행합니다.
5. 모든 카드가 사라지면 점수를 계산합니다.
6. 가장 높은 점수를 얻은 사람이 승리합니다.

## 교육적 활용

* 부산의 문화유산을 쉽고 재미있게 익힐 수 있습니다.
* 시대별 유산 분류 능력을 기를 수 있습니다.
* 카드 설명 읽기를 통해 핵심 정보를 반복 학습할 수 있습니다.
* 게임 후 좋아하는 유산을 발표하며 표현·소통 능력을 기를 수 있습니다.

## 활용 예시

* 초등학교 4학년 사회과 지역화 수업
* 부산 문화유산 탐구 활동
* 모둠별 보드게임 수업
* 역사·문화유산 복습 활동
